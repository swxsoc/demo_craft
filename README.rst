``demo_craft`` is the instrument package for the ``craft`` instrument of the
SWxSOC ``demo`` mission. The demo mission has no spacecraft; it exists to prove
the shared Science Data Center (SDC) pipeline in
`swxsoc/sdc_aws_architecture <https://github.com/swxsoc/sdc_aws_architecture>`_
end to end, from an upload to the incoming bucket through sorting, processing
and the artifacts Lambda. This package is the known-good instrument that the
scheduled smoke test there uploads data for.

What it does
------------

``demo_craft.calibration.process_file`` is the entry point the SDC processing
Lambda calls. Given one level 0 file it writes exactly one level 1 file and
returns its path; given a level 1 or higher file it returns an empty list, so
the processing chain stops after one step and every upload yields exactly one
processed object. Filenames that are not for the demo mission's craft
instrument raise ``ValueError``, which the Lambda treats as "skip".

The data products are deliberately tiny and dependency free:

* **Level 0** (``demo_craft_l0_<YYYYmmddTHHMMSS>_v<X.Y.Z>.csv``): a CSV file
  with ``time`` (ISOT) and integer ``counts`` columns, one row per second.
* **Level 1** (``demo_craft_l1_<same time>_v0.0.1.csv``): the same rows with a
  ``flux`` column added, ``flux = gain * counts + offset`` using the gain and
  offset in ``demo_craft/data/calibration``.

Filenames follow the SWxSOC convention
``{mission}_{inst}_{mode}_{level}{test}_{descriptor}_{time}_v{version}.{ext}``.
Because the ``demo`` mission in the shipped ``swxsoc`` configuration does not
yet list a ``craft`` instrument, the convention is implemented locally in
``demo_craft.util.filename``; see the TODO there.

Test data
---------

``demo_craft/data/test`` ships one synthetic level 0 file,
``demo_craft_l0_20260101T000000_v0.0.1.csv``, generated by
``demo_craft.util.synthetic``. With ``USE_INSTRUMENT_TEST_DATA=True`` the
processing Lambda runs ``process_file`` on it instead of downloading from S3,
which lets the pipeline be exercised without any upload.

Usage
-----

.. code-block:: python

    from demo_craft.calibration import process_file

    outputs = process_file("demo_craft_l0_20260101T000000_v0.0.1.csv")
    # [PosixPath('demo_craft_l1_20260101T000000_v0.0.1.csv')]

Install the package with ``pip install demo_craft @ git+https://github.com/swxsoc/demo_craft.git@v0.0.1``.
For development, ``pip install -e ".[dev]"`` then ``pytest`` and ``ruff check .``.
